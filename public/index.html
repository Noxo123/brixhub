Authentification
Les requêtes authentifiées utilisent le header X-API-Key. Les clés commencent par brix_.
X-API-Key: brix_votre_cle_api
Content-Type: application/json
Ne publiez jamais une clé API dans un dépôt public ou du code frontend. Utilisez une variable d'environnement côté serveur.

Exemple JavaScript
Appelez l'API depuis votre backend et gardez la clé dans une variable d'environnement.
const r = await fetch('https://api.brixhub.to/api/v1/search', {
  method: 'POST',
  headers: {
    'X-API-Key': process.env.BRIXHUB_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    nom_famille: 'Dupont',
    prenom: 'Jean',
    ville: 'Paris',
    flexible: true,
    per_page: 10
  })
});
const data = await r.json();
